# Known issues and open points

This file lists everything in the manuscript or the package that is not yet verified. It is
kept in sync with `docs/CONSISTENCY_REPORT.md` (generated by `tools/check_consistency.py`).

## A. Results that require re-running the experiments

1. **No archived outputs.** The per-seed predictions behind Tables 1 to 10, the significance
   tests and Figures 3 to 9 were not archived. This package can regenerate them but has not yet
   been executed end to end (GPU + OpenAI API needed).
2. **Abstention rate vs recall (Tables 5 and 10; checks C20, C21).** Both are defined on the
   5,945 unanswerable questions and should coincide (e.g. 78.91% vs recall 0.81 at tau = 0.75).
   In addition, abstention precision cannot be computed on unanswerable questions only, although
   the Table 10 caption says so. `edugpt_rag.metrics.abstention_metrics` computes precision over
   all abstentions and recall over unanswerable questions.
3. **Tables 2 and 4 (checks C22, C23).** "- Cross-encoder re-ranking" in Table 4 (EM 84.18)
   keeps CoT and verification yet is lower than "Hybrid, no re-rank" in Table 2 (EM 85.12), and
   the Table 4 dense-only and BM25-only rows equal the Table 2 rows although the configurations
   differ.
4. **Index size (Table 7; Sections 4.8 and 4.10; check C33).** An IVF4096,PQ64 index over the
   20,238 chunk vectors is about 15 MB, not 2.4 GB. `latency_benchmark.py` measures index size.
5. **FAISS training sample (check C34).** The corpus has 20,238 chunks, so the IVF-PQ index is
   trained on all of them (the manuscript now says "up to 100K"). FAISS recommends at least
   39 x 4096 = 159,744 training points for IVF4096 and prints a warning.
6. **Recall@5 t-test against Self-RAG (check C27).** Table 1 gives no per-seed variation for
   Self-RAG Recall@5, so the reported t(2) = 11.54 cannot be recomputed.
7. **Run-time statements.** "Encoding the passage chunks in about 45 minutes" and "about 4 hours"
   for re-ranker fine-tuning on the 40M-triple MS MARCO file are not consistent with the corpus
   size and data size; `training_args.json` and the logs of a re-run will give measured values.
8. **Human evaluation (check C35).** Annotations, rubric version and annotator details were not
   archived. `evaluation/human_eval/` provides a blinded protocol and analysis script.
9. **Independent metric validation (Reviewer 1, Comment 2).** Not performed for V9.
   `evaluation/independent_metric_check.py` runs a second NLI model (RoBERTa-large-MNLI) and an
   LLM judge and reports agreement with confidence intervals.

## B. Implementation choices not specified in the manuscript

1. Tokens for chunking are whitespace-delimited; sentence boundaries use NLTK Punkt.
2. The "- CoT prompting" ablation uses `DIRECT_PROMPT` (same grounding instruction, no reasoning
   steps); the manuscript does not give this prompt.
3. Closed-book systems (Vanilla GPT-4, REALM) are scored for hallucination against the final
   contexts of the EduGPT-RAG run for the same question (recorded per row as `nli_context_source`).
4. ColBERT-QA: the manuscript names the retriever (ColBERTv2 + PLAID) but not the reader; the
   package uses GPT-3.5-turbo with the Appendix A.1 prompt.
5. Self-RAG uses a re-implementation of short-form inference with retrieval threshold 0.5;
   it should be cross-checked against the official repository before reporting.
6. Contamination probes: paraphrases are produced by GPT-3.5-turbo and entity substitutes come
   from Wikidata (PERSON, GPE, ORG); the manuscript does not state either method.
7. LangChain (cited in Section 4.1) is not needed by this implementation and is not installed.
8. Metric denominators: Recall@K and MRR use all 11,873 development questions (each SQuAD 2.0
   question, answerable or not, was written on one source paragraph); Faithfulness (Eq. 15) is
   averaged over non-abstained answers; Hallucination rate is computed over all questions, an
   abstention counting as not hallucinated; Citation accuracy over answers that cite a passage.
9. FiD and Atlas have no Hugging Face checkpoints; they run through export/import adapters around
   the official repositories (docs/BASELINES.md).

## C. QASPER

Manuscript V9 reports no quantitative QASPER results. `data/build_corpus_qasper.py` and
`experiments/run_qasper.py` implement the protocol on the official v0.3 split (888 training,
281 development, 416 test papers; 1,005 development questions) for future reporting. The
earlier QASPER script, which indexed only part of the validation split, has been removed.
